## yihong-video 全自动视频生成skill

把一个字幕文件，做成带配音、烧录字幕、带鼠标操作演示的竖屏视频（MP4）。
画面由程序化图形承载旁白——等距装置、流程图、数据看板、界面操作，不是录屏，也不是几个方块配文字。

## 三步出片

1. **选 skill**：在 WorkBuddy 里选 `yihong-video`。
2. **选字幕**：准备一份字幕 txt，随便找个 AI 就能生成；样例见 `example/字幕.txt`。
3. **等成片**：配音、场景切分、强制对齐、画画面、逐帧录制、合成，AI 全自动完成。

每天用 WorkBuddy 的免费积分就能生成好几个视频。**选的模型越强，视频效果越好。**

首次运行需要 `ffmpeg` 和 Playwright，缺了 AI 会给出安装命令。

## 配音

- 默认走 **Gemini TTS**，每天免费额度可以生成几万字的配音；自备 `GEMINI_API_KEY`。
- 没有 Key 时，使用**本地 edge-tts**。
- **觉得语速太慢**：让配音整体 1.2 倍速即可，1.2 倍以内基本无损。

## 不满意就改

- **背景水印**：在 `styles.css` 里修改，文字、位置、透明度都集中在这一个文件。
- **哪段不满意**：直接告诉 AI 改哪一段，只重录该场景，不用整片重来。
- **图形太素**：让 AI 加细节（刻度、编号、光影、标注），并打开 `assets/stage/kit-demo.html` 看样张。

## 目录

| 路径 | 说明 |
|---|---|
| `example/字幕.txt` | 字幕样例，可直接改成自己的文案 |
| `assets/stage/` | HTML 舞台模板，含绘图工具箱与图元样张 |
| `scripts/` | 配音、逐词转写、对齐、录制、合成、同步自检 |
| `references/` | 完整流程、图形规范、设计规范、踩坑表 |

完整命令与验收标准见 `references/pipeline.md`。核心只有一句：先做声音，再做画面——时间轴必须从真实音频反推。
