# 视觉规范

竖屏 800×1000。所有尺寸都是实测能用的值，改动前先想清楚会不会溢出。

## 栅格

| 区域 | 位置 | 说明 |
|---|---|---|
| 页头 `.hdr` | top 32, left 44, w 712 | 品牌名 + 场景序号 |
| 标题区 `.head` | top 82, left 44, w 712 | kicker / 标题 / 副标题 |
| 内容区 `.body` | top 236, left 44, **w 712 × h 600** | 所有主体元素 |
| 字幕底衬 `.subscrim` | bottom 0, h 190 | 渐变压暗，保证字幕可读 |
| 字幕位置 | y = 900（中心） | ASS `\pos(400,900)` |

内容区下沿 836，字幕中心 900、字高 32 → 字幕上沿约 878。
**主体元素底边不要越过 850**，否则会和字幕打架。

## 间距与圆角

`styles.css` 里已经把这套值定义成 CSS 变量，写场景时只用这几档，不要现编 11px、18px：

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--sp1` | 4px | 图标与文字、标签内边距 |
| `--sp2` | 8px | 标题与正文、胶囊间距 |
| `--sp3` | 12px | kicker→标题、标题→副标题 |
| `--sp4` | 16px | 卡片内元素行距、横向元素间隙 |
| `--sp5` | 20px | 卡片内边距（四边相同） |
| `--sp6` | 24px | 卡片之间、区块之间 |
| `--r-card` | 16px | 卡片 / 面板 |
| `--r-btn` | 12px | 按钮、输入框 |
| 胶囊 | 高的一半 | 状态标签 |

四条对齐规则（画面"歪"基本都是没守这四条）：

1. **一套内边距**：卡片四边都是 20，不要 18/20 混用——上下和左右不一致，眼睛一眼看出。
2. **一条左基准线**：卡片标题、正文、列表、图表标签全部对齐到内边距那条线；有图标的标题，
   正文要跟着让位（`c.node()` 已处理）。
3. **强调条让开圆角**：左侧色条用 `c.accent()` 或收短到圆角区内，方角从圆角里探出来是最显廉价的一处。
4. **底边对齐**：同一屏里的卡片、柱区、结论条，尽量让底边落在同一条水平线上（如 836）。

字幕用**深色字 #2E2114 + 白色描边 3.2px**。浅色背景上白字会糊，必须反着来。

## 光标

22×26 的半透明小箭头（SVG，fill #16233b、opacity .55、白描边 1.4）。
太大太实会抢戏，太小看不见。悬停加 `.cur-hover`（蓝色 outline + 阴影），
按下加 `.press`（brightness .93）。

## 动画时序

每个场景内部统一用：

```js
const F = d - 0.45, P = (x) => x * F;   // d = 场景时长
```

- 入场 0 → P(0.30)，元素依次错开 0.04~0.06
- 主体动作 P(0.25) → P(0.75)
- **最后 0.3s 必须留给收尾**：光标与配音内容关联，动作播完、再切场景
- 光标轨迹与点击都写成 `d` 的比例，这样改时长不用重排

## 三种以上交互元素

"交互元素"指观众能看出可以操作的东西：卡片、按钮、表格、输入框、
下拉、进度条、连线、拖拽、文件、图标、光标点击。

每屏至少 3 种，且**光标必须真的动、真的点**——静帧 + 文字是 PPT，不是演示视频。

## 密度与层次

内容区 712×600 不是"能放多少字"的约束，是"能放多少层"的约束。
一屏按五层组织，从上到下依次压住：

| 层 | 放什么 | 典型元素 |
|---|---|---|
| `bg` | 背景网格、分区底色、水印 | 极淡，不要抢主体 |
| `struct` | 主体结构：装置 / 节点 / 图表 / 窗口 | 占 60~70% 面积 |
| `content` | 主体上的内容：液位、柱、文字、图标 | 依附在 struct 上 |
| `fx` | 流动、扫描线、粒子、高亮 | 一律半透明，不加不减色 |
| `annot` | 引导线标签、图例、单位、序号 | 永远在最上，且**不压在主体文字上** |

密度参考值（`document.querySelectorAll("#scN *").length`）：

- 40 以下：看起来像"几个方块"，需要加细节阵列或标注
- 40~120：正常区间
- 150 以上：多半信息过载，拆场景或减层级

"精细"的量化标准：一屏里至少出现 **3 类细节词汇**——刻度、纹理/阵列、编号、
光影（投影/高光）、标注（引线/图例/单位）。四类以上就有"仪表感"。
具体图元与写法见 `scene-graphics.md`。

## 数字与一致性

- 图表数值要和文案口径一致，合计要真的加得上（做完用计算器核一遍）
- 计数动画从 0 起跳，用 `ease` 而不是线性，最后必须停在正确值
- 同一屏里不要出现两个互相矛盾的数字（例如"改了 1 段"却显示"改动 0 字节"）
